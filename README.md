# Telegram Giveaway Bot 🤖🎉

یک ربات ساده، سریع و کاربردی برای برگزاری قرعه‌کشی در تلگرام، توسعه‌داده‌شده با پایتون و کتابخانه `aiogram 3`.

## قابلیت‌ها
* ثبت‌نام کاربران با یک کلیک (دکمه شیشه‌ای)
* جلوگیری از ثبت‌نام تکراری کاربران
* قابلیت مشاهده آنلاین تعداد شرکت‌کنندگان
* دستور ادمین (`/draw`) برای انتخاب تصادفی برنده

## نحوه راه‌اندازی و اجرا
1. پایتون (نسخه ۳.۹ به بالا) را روی سیستم یا سرور خود نصب کنید.
2. کتابخانه‌های موردنیاز را با دستور زیر نصب کنید:
   ```bash
   pip install -r requirements.txt
